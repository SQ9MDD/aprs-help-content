APRSISCE/32 is one of the most feature-rich classic APRS clients. It combines APRS mapping, APRS-IS, radio and TNC support, messaging, objects and items, telemetry, weather, iGate, beaconing, station tracking, Direction Finding, MultiLine, area objects, NWS-WARN and advanced APRS-IS filtering.

Project documentation:

https://aprsisce.wikidot.com/

Download:

https://aprsisce.wikidot.com/downloads

https://groups.io/g/APRSISCE

## APRSISCE and APRSIS32

APRSISCE was the Windows Mobile/CE version. APRSIS32 is the desktop Windows version and also runs on 64-bit Windows.

## Full APRS terminal

With a radio and TNC it can receive RF, display stations, send beacons, exchange messages, gate traffic and manage APRS objects.

## Maps and tracking

It uses tiled maps, primarily OpenStreetMap, supports local cache, MultiTrack and GPX track history.

## Scroller

The Scroller gives a fast view of current APRS traffic and helps distinguish direct RF, gated and digipeated packets.

## Radio and modem support

It supports classic TNCs, KISS, Kenwood APRS radios, AGWPE, UZ7HO SoundModem, Dire Wolf, serial ports and network connections.

## KISS and AGW

KISS can be used directly, while AGW allows integration with software modems such as Dire Wolf and SoundModem.

## APRS-IS and advanced filters

RF and APRS-IS can be combined in one view. Filters can select traffic by area, radius, callsign, prefix, digipeater, iGate, object, symbol, packet type and group messages.

## iGate

APRSIS32 can operate as an iGate in both RF to IS and controlled IS to RF directions.

## Digipeater

It also includes digipeater functions and path transformations such as `WIDE1-1=WIDE1*`.

## APRS messaging

It supports APRS messages, message IDs, ACKs, retransmissions and RF/APRS-IS message paths.

## Objects and items

Advanced object support includes repeaters, frequency objects, meeting points, hazards, technical stations and activity locations.

## Frequency objects

It interprets APRS Frequency Specification such as `145.650MHz T077 -060`.

## QRU APRS Info-kiosk

QRU can keep large object databases locally and transmit only objects requested by the user.

## MultiLine and area objects

MultiLine supports lines, routes, boundaries, polygons and area objects.

## NWS-WARN

NWS-WARN support can combine received warning objects with local SHP/SHX/DBF shapefiles to display precise warning areas.

## Direction Finding

The program can interpret and visualise APRS Direction Finding packets and DF circles for triangulation and transmitter location.

## Weather and telemetry

It supports APRS weather, standard telemetry and weather generation from `wxnow.txt`.

## APRS Queries

Standard APRS queries such as `?APRS?`, `?IGATE?` and `?WX?` are supported.

## Item-In-Message

It supports the Item-In-Message mechanism.

## Satellites

TLE-based satellite tracking and MultiLine footprint visualisation are supported.

## Duplicate frames

Duplicate detection helps keep mobile station tracks correct when the same position arrives by different paths.

## Beaconing and GPS

Own position can come from static configuration, GPS, NMEA, USB or Bluetooth GPS.

## Windows, Linux and Wine

APRSIS32 is a Windows application, but documentation also covers operation under Linux using Wine.

## Current project status

Windows Mobile/CE versions are mainly historical, while APRSIS32 remains available for modern Windows.

## APRS protocol compatibility

Its broad APRS coverage includes positions, compressed positions, symbols, messages, ACKs, status, telemetry, weather, objects, items, frequency data, queries, NWS objects, MultiLine, area objects, DF and Item-In-Message.

## Who is APRSISCE/32 for?

It is useful for operators who want mapping, RF, messaging, iGate, objects, areas, Direction Finding, weather and advanced APRS experimentation.

## Summary

APRSISCE/32 is one of the most complete classic APRS clients and demonstrates how much more APRS can carry than position reports alone.
